## 🏛️ Official

**Essential official resources from the Moodle team** - Your trusted source for authentic Moodle documentation, tools, and community support. These official resources are maintained by Moodle HQ and represent the most reliable and up-to-date information about the Moodle learning management system.

- 🌐 [Moodle.org](https://moodle.org/) - The official Moodle website and community hub serving millions of educators and learners worldwide. Access the central repository for all Moodle-related information, community forums, and official announcements
- 📖 [Moodle Documentation](https://docs.moodle.org/) - Comprehensive official documentation for all Moodle versions. This extensive knowledge base covers installation, administration, teaching strategies, and development for every Moodle release
- 👨‍💻 [Moodle Developer Resources](https://moodledev.io/) - Official developer documentation and guides for creating plugins, themes, and custom integrations. Essential for developers building extensions and customizations
- 🎓 [Moodle Academy](https://moodle.academy/) - Free courses for educators, administrators, and developers. Earn official Moodle certifications and develop professional skills in teaching, administration, and development
- 📦 [GitHub Repository](https://github.com/moodle/moodle) - Official Moodle source code on GitHub. Access the complete codebase, contribute to development, and track the latest updates
- 🔄 [Git Repository](https://git.moodle.org/) - Primary official Moodle git repository maintained by Moodle HQ. The authoritative source for Moodle code and version control
- 📋 [Release Information](https://moodledev.io/general/releases) - Version support and release details for all Moodle versions. Understand support timelines, LTS versions, and upgrade paths
- ⬇️ [Downloads](https://download.moodle.org/releases/latest/) - Latest official Moodle releases and previous versions. Download the Moodle software directly from the official source
- 🗺️ [Roadmap](https://moodledev.io/general/roadmap) - Future development plans and upcoming features. Stay informed about the direction of Moodle development
- 📊 [Statistics](https://stats.moodle.org/) - Global Moodle usage statistics and adoption metrics. See how Moodle is used worldwide across educational institutions
