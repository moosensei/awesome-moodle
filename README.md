## Official

*   [Moodle.org](https://moodle.org/) - The official Moodle website and community hub.
*   [Moodle Documentation](https://docs.moodle.org/) - Comprehensive official documentation for all Moodle versions.
*   [Moodle Developer Resources](https://moodledev.io/) - Official developer documentation, guides, and resources.
*   [Moodle Academy](https://moodle.academy/) - Free online courses to develop your skills as a Moodle educator, administrator, designer, or developer.
*   [Moodle GitHub Repository](https://github.com/moodle/moodle) - The official Moodle source code repository.
*   [Moodle Git Repository](https://git.moodle.org/) - The primary location of the official Moodle git repository.
*   [Moodle Releases](https://moodledev.io/general/releases) - Official release information and version support details.
*   [Moodle Downloads](https://download.moodle.org/releases/latest/) - The latest official Moodle releases available for download.

## Plugins

*   [Moodle Plugins Directory](https://moodle.org/plugins) - The official repository for Moodle plugins, with contributions from the community.
*   [H5P](https://h5p.org/moodle) - Create, share and reuse interactive HTML5 content in your Moodle courses.
*   [iSpring Suite](https://www.ispringsolutions.com/ispring-suite) - A powerful authoring tool that allows you to create interactive courses and assessments and publish them to Moodle.
*   [Edwiser Course Formats](https://edwiser.org/course-formats/) - A plugin that provides different course layouts to make your Moodle courses more engaging.
